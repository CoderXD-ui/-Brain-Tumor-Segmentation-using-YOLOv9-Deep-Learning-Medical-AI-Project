# 🧠 Brain Tumor Segmentation using YOLOv9 | Deep Learning Medical AI Project

In this project, we’ll walk through the **end-to-end implementation** of a **Brain Tumor Segmentation** model using **YOLOv9**, one of the most advanced deep learning architectures for real-time object detection and segmentation.

## 📘 Project Overview
You’ll learn how to:
* ✅ Download and organize the **Brain Tumor Segmentation dataset** automatically using `gdown`
* ✅ Configure the **dataset YAML** for YOLOv9 segmentation
* ✅ Train the YOLOv9 model with **data augmentation** for better performance
* ✅ Visualize the **segmentation results** using OpenCV and Matplotlib
* ✅ Understand the **code flow** for both training and testing

This project is ideal for anyone looking to explore **medical image analysis, segmentation, and model training** using **Ultralytics YOLOv9**. Whether you're a **student, researcher, or AI enthusiast**, this repository will guide you through building and deploying your own medical imaging model from scratch.

## 🚀 Technologies Used
* Python
* Ultralytics YOLOv9
* OpenCV
* Matplotlib
* NumPy
